## 关于「star 不等于复制」

在 GitHub 上点 star 只是**收藏**，不会把别人的仓库复制到你自己名下，所以「我的仓库」里不会自动出现它们。这个索引仓库就是替代方案：它在你名下，侧边栏能点开，同时所有代码都还留在原作者仓库里，别人更新了你看的也是最新版。

如果你确实想要一份自己的副本（比如要改代码），那才需要 **fork**（派生）：fork 会在你名下生成一个副本，并链接回原仓库。注意 fork 出来的仓库通常**不能设为私有**，而且会一直挂在你的主页上。

## 怎么更新这份索引

已登录 `gh` 的前提下，一条命令就能看当前 star 列表：

```bash
gh api "/users/ynxlna666/starred?per_page=100" \
  --jq '.[] | "\(.full_name) ★\(.stargazers_count) \(.language // "-")"'
```

想重新生成整份索引，把新结果交给 AI 让它改写本文件即可；`stars.json` 是同一次抓取的机器可读快照。
